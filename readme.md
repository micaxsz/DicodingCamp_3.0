feat Menambahkan fitur baru
fix Memperbaiki bug
docs Perubahan hanya pada dokumentasi (README, JSDoc)
style Perubahan format kode yang tidak mengubah logika (spasi, indentasi, semicolon)
refactor Mengubah struktur kode tanpa mengubah perilaku/fitur
perf Perubahan yang meningkatkan performa eksekusi
test Menambah atau memperbaiki kode pengujian (unit test)
build Perubahan pada build system atau dependensi eksternal (npm, webpack)
ci Perubahan konfigurasi CI/CD (GitHub Actions, GitLab CI)
chore Tugas rutin pemeliharaan yang tidak termasuk kategori lain
revert Membatalkan commit sebelumnya
